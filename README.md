## 项目介绍

香菜工作台是一套面向自媒体创作者的**多平台内容自动化发布系统**，整合了文章全生命周期管理、百家号信息流标题采集、5平台AI账号管理、指令队列实时监控等核心能力。

系统采用**前后端分离**架构：
- **前端**：Vue 3 + Arco Design Vue，提供现代化的管理界面
- **后端**：FastAPI + SQLite，提供 RESTful API 和 WebSocket 实时推送

## 快速开始

### 环境要求

| 软件 | 最低版本 | 推荐版本 |
|------|---------|---------|
| Node.js | 16.0 | 18.x / 20.x |
| npm | 8.0 | 9.x / 10.x |
| Python | 3.9 | 3.10 / 3.11 |
| pip | 21.0 | 最新版 |

> ⚠️ **注意**：Python 不建议使用 3.13 等过新版本，部分依赖库（如 uiautomator2）可能不兼容。推荐使用 Python 3.10 或 3.11。

### 安装步骤

#### 1. 克隆或下载项目

将项目放置到任意目录，例如：
```
D:\Tools\罐头\xiangcaipy
```

#### 2. 安装前端依赖

```bash
cd xiangcaipy
npm install
```

#### 3. 安装后端依赖

```bash
cd server
pip install -r requirements.txt
```

## 启动方式

### 方式一：双击启动脚本（推荐 Windows 用户）

项目根目录提供了两个启动脚本：

| 脚本 | 作用 | 端口 |
|------|------|------|
| `start_frontend.bat` | 启动前端开发服务器 | 5173 |
| `start_server.bat` | 启动后端 FastAPI 服务 | 8000 |

**使用方法**：
1. 双击 `start_server.bat` 启动后端（等待显示 "Application startup complete"）
2. 双击 `start_frontend.bat` 启动前端（等待显示 "Local: http://localhost:5173"）
3. 打开浏览器访问 `http://localhost:5173`

### 方式二：命令行启动

#### 启动后端

```bash
cd xiangcaipy\server
python main.py
```

后端启动成功后会显示：
```
INFO:     Uvicorn running on http://0.0.0.0:8000
INFO:     Application startup complete.
```

#### 启动前端

新开一个命令行窗口：

```bash
cd xiangcaipy
npm run dev
```

前端启动成功后会显示：
```
  VITE v5.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

### 方式三：生产构建部署

```bash
# 构建前端
cd xiangcaipy
npm run build

# 构建产物在 dist/ 目录，可部署到 Nginx 等静态服务器
# 后端使用 uvicorn 生产启动：
cd server
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 2
```

### 2. 工作台

**功能说明**：

- 近7天文章生成、图片生成、存草稿的数量趋势
- 鼠标悬停可查看具体数值
- 可点击图例切换显示/隐藏某条线

#### 2.3 平台账号分布图
- 环形饼图展示5个平台的账号数量占比
- 鼠标悬停查看具体数量和百分比

#### 2.4 热门标题 TOP5
- 按阅读量排序的前5条热门标题
- 显示阅读量、评论数、点赞数
- 前三名红色标记

#### 2.5 文章状态分布图
- 柱状图展示6种文章状态的数量
- 状态包括：待生成、生成中、成功、失败、草稿中、已导出

#### 2.6 快捷操作
- **文章管理**：跳转到文章列表
- **标题采集**：跳转到标题采集页
- **批量导入**：跳转到批量导入页

- **排版设置**：跳转到排版设置
- **指令队列**：跳转到指令队列

### 3. 文章管理

**访问路径**：`/article`

#### 3.1 筛选功能
- **状态筛选**：下拉选择文章状态（待生成/生成中/成功/失败/草稿中/已导出等11种）
- **话题筛选**：按话题分类筛选
- **关键词搜索**：输入标题关键词搜索，支持回车快捷搜索
- **重置**：一键清空所有筛选条件

#### 3.2 表格列说明
| 列 | 说明 |
|----|------|
| 复选框 | 用于批量选择 |
| ID | 文章唯一编号 |
| 标题 | 文章标题，点击可跳转详情 |
| 话题 | 所属话题分类 |
| AI类型 | 使用的AI模型（仰度老系统/仰度新系统/智谱web） |
| 状态 | 文章当前状态（彩色标签） |
| 创建时间 | 文章创建时间 |
| 操作 | 详情/重新生成/导出/删除 |

#### 3.3 单篇操作
- **详情**：跳转到文章详情页，查看正文和图片
- **重新生成**：提交文章重新生成指令
- **导出**：将文章导出为Word文档
- **删除**：删除文章（带确认弹窗）

#### 3.4 批量操作
勾选文章后，顶部出现批量操作栏：
- **批量重新生成**：批量提交重新生成
- **批量导出**：批量导出为Word
- **批量删除**：批量删除（带确认弹窗，不可恢复）

#### 3.5 新建文章
1. 点击右上角"新建文章"按钮
2. 填写标题（必填）、话题、AI类型、限定提示词
3. 点击"确定"创建文章
4. 文章初始状态为"待生成文章"

#### 3.6 下载模板
点击"下载模板"按钮，下载Excel批量导入模板文件。

### 4. 批量导入

**访问路径**：`/article/batch-import`（从文章管理页点击"批量导入"进入）

**操作步骤**：
1. 点击"下载模板"下载Excel模板
2. 按模板格式填写标题数据（标题必填，话题/AI类型/文章类型/限定提示词可选）
3. 将Excel文件拖拽到上传区域，或点击区域选择文件
4. 系统自动解析并显示预览
5. 确认无误后点击"开始导入"
6. 导入完成后显示成功/失败数量

**模板字段说明**：
| 字段 | 必填 | 说明 |
|------|------|------|
| 标题 | 是 | 文章标题 |
| 话题 | 否 | 话题分类名称 |
| AI类型 | 否 | yangdu_old / yangdu_new / zhipu |
| 文章类型 | 否 | free（免费）/ paid（付费） |
| 限定提示词 | 否 | 对AI生成的额外限定条件 |

### 6. 标题采集

**访问路径**：`/title-spider`

#### 6.1 爬虫控制
- **启动采集**：点击绿色"启动采集"按钮，爬虫开始运行
- **停止采集**：点击红色"停止采集"按钮，爬虫停止运行
- **刷新**：手动刷新标题列表
- 状态标签显示当前爬虫运行状态（绿色=采集中，灰色=已停止）

#### 6.2 统计卡片
- **今日采集**：今日新采集的标题数量
- **总标题数**：标题库中所有标题数量
- **已使用**：已标记为"已用"的标题数量
- **待使用**：未使用的标题数量

#### 6.3 筛选功能
- **阅读量**：输入最低阅读量，筛选高阅读量标题
- **分类**：按分类筛选（家庭伦理/职场故事/情感故事）
- **状态**：按使用状态筛选（未使用/已使用）
- **关键词**：按标题关键词搜索

#### 6.4 表格列说明
| 列 | 说明 |
|----|------|
| 复选框 | 批量选择 |
| ID | 标题唯一编号 |
| 标题 | 采集到的标题文本 |
| 阅读量 | 阅读量，超过1万红色显示，支持排序 |
| 评论 | 评论数 |
| 点赞 | 点赞数 |
| 分类 | 标题分类 |
| 状态 | 未使用（绿色）/已使用（灰色） |
| 采集时间 | 采集时间 |
| 操作 | 复制/标记/生成文章/删除 |

#### 6.5 单篇操作
- **复制**：复制标题到剪贴板
- **标记/取消**：切换标题使用状态
- **生成文章**：基于该标题生成文章
- **删除**：删除该标题

#### 6.6 批量操作
勾选标题后，顶部出现批量操作栏：
- **批量标记已用**：批量标记为已使用
- **批量取消标记**：批量取消已使用标记
- **导出选中**：导出选中的标题
- **批量删除**：批量删除标题

#### 6.7 数据导出
- **导出全部为CSV**：点击按钮，将当前筛选结果导出为CSV文件
- CSV文件包含：ID、标题、阅读量、评论数、点赞数、分类、状态、采集时间
- 文件使用UTF-8 BOM编码，Excel直接打开不乱码
- 文件名格式：`标题采集_YYYY-MM-DD.csv`

#### 6.8 采集日志
- 底部显示采集运行日志
- 包含时间、消息内容
- 支持清空日志
- 实时显示爬虫运行状态

### 7. 账号管理

**访问路径**：`/account/*`（侧边栏"账号管理"展开子菜单）

系统支持 **5个平台** 的账号管理：

| 平台 | 路由 | 说明 |
|------|------|------|
| 百家号 | `/account/baijiahao` | 内容发布平台，支持自动登录、存草稿、发布 |
| 豆包 | `/account/doubao` | AI图片生成，多账号轮询均衡 |
| 仰度AI | `/account/yangdu` | AI文章生成，支持老系统/新系统/智谱web三种类型 |
| 智谱AI | `/account/zhipu` | AI文章生成，Web端自动化 |
| 元宝 | `/account/yuanbao` | AI对话，支持DeepSeek/Hunyuan模型 |

#### 7.1 账号列表
每个平台页面显示该平台的所有账号，包含：
- **用户名**：账号登录名
- **账号类型**：部分平台支持多种类型（如仰度AI的老系统/新系统/智谱web）
- **登录状态**：未登录（红色）/已登录（绿色）
- **浏览器状态**：未启动/初始化/检查登录/未登录/运行中
- **启用状态**：启用（绿色）/禁用（灰色）
- **今日发布数**：今日已发布文章数量
- **备注**：账号备注信息

#### 7.2 账号操作
- **新增账号**：点击"新增账号"，填写用户名、密码、Cookie、备注、账号类型
- **编辑**：修改账号信息
- **删除**：删除账号（带确认）
- **触发登录**：启动浏览器自动登录该账号
- **启用/禁用**：切换账号启用状态，禁用后不参与自动任务

#### 7.3 表单验证
- 用户名：必填
- 密码：必填（或填写Cookie）
- 账号类型：部分平台必选

### 9. 指令队列

**访问路径**：`/command`

#### 9.1 统计卡片
- **待执行**：等待执行的指令数量
- **执行中**：正在执行的指令数量
- **已完成**：成功完成的指令数量
- **失败**：执行失败的指令数量

#### 9.2 实时监控
- 页面通过 WebSocket 实时接收指令状态更新
- 连接状态标签：绿色=实时连接，灰色=未连接（自动重连）
- 指令状态变化实时刷新，无需手动刷新

#### 9.3 指令类型
| 类型 | 说明 |
|------|------|
| trigger_login | 触发账号登录 |
| scan_qrcode | 扫描二维码登录 |
| message_code | 短信验证码 |
| generate_article | 生成文章正文 |
| generate_image | 生成文章图片 |
| baijiahao_draft | 百家号创建草稿 |

#### 9.4 操作
- **重试**：对失败的指令重新执行
- **详情**：查看指令详细信息和执行结果
- **清空指令**：清空所有已完成和失败的指令（待执行/执行中的保留）
- **刷新**：手动刷新列表

#### 9.5 实时日志
- 底部显示指令执行实时日志
- 包含时间、消息内容、级别（info/warn/error/success）
- 支持清空日志

### 10. 日志监控

**访问路径**：`/logs`

#### 10.1 级别统计卡片
- **INFO**：信息日志数量
- **WARNING**：警告日志数量
- **ERROR**：错误日志数量
- **DEBUG**：调试日志数量

#### 10.2 日志查询
- **级别筛选**：下拉选择日志级别（INFO/WARNING/ERROR）
- **关键词搜索**：输入关键词搜索日志内容，支持回车快捷搜索
- **自动刷新**：开关控制，开启后每5秒自动刷新日志
- **手动刷新**：点击刷新按钮

#### 10.3 日志列表
- 每条日志显示：时间、级别标签、日志来源（logger名称）、消息内容
- ERROR级别红色背景高亮

### 前端代理配置

前端开发服务器通过 Vite 代理将 `/api` 请求转发到后端：

```js
// vite.config.js

```

## 配置说明

### 前端配置

#### 修改前端端口
编辑 `vite.config.js`：
```js
server: {
  port: 5173,  // 修改为其他端口
  host: '0.0.0.0'  // 允许局域网访问
}
```

#### 修改后端代理地址
编辑 `vite.config.js`：
```js
proxy: {
  '/api': {
    target: 'http://127.0.0.1:8000',  // 修改为后端实际地址
    changeOrigin: true
  }
}
```

#### 修改API基础地址
在系统运行时，也可以通过 Pinia store 动态修改：
```js
import { useAppStore } from '@/stores/app'
const appStore = useAppStore()
appStore.setApiBaseUrl('http://your-backend:8000')
```

### 后端配置

#### 修改后端端口
编辑 `server/main.py` 末尾：
```python
uvicorn.run(
    "main:app",
    host="0.0.0.0",
    port=8000,  # 修改为其他端口
    reload=True
)
```

#### 修改数据存储目录
默认数据存储在 `server/data/` 目录下。如需修改，编辑各 API 文件中的 `DATA_FILE` 路径。

#### 修改日志配置
编辑 `server/utils/logger.py`：
- 日志文件路径：`data/logs/xiangcai.log`
- 单文件大小：10MB
- 保留文件数：5个
- 内存缓冲区：最多500条

## 常见问题

### Q1：启动前端报错 "Cannot find module"
**A**：依赖未安装，执行：
```bash
npm install
```

### Q2：启动后端报错 "ModuleNotFoundError: No module named 'fastapi'"
**A**：后端依赖未安装，执行：
```bash
cd server
pip install -r requirements.txt
```

### Q3：前端页面显示空白或接口报错
**A**：检查后端是否已启动。前端通过 `/api` 代理访问后端，后端必须先启动。
- 后端地址：http://127.0.0.0:8000
- 健康检查：http://127.0.0.1:8000/api/health

### Q4：登录后又跳回登录页
**A**：Token过期或被清除。检查浏览器 localStorage 中是否有 `xiangcai_token`。
- 解决方法：重新登录，或在开发者工具 Application → Local Storage 中手动添加 token

### Q5：CSV导出文件用Excel打开乱码
**A**：系统导出的CSV已使用UTF-8 BOM编码，Excel 2016+可直接打开不乱码。
- 如果仍乱码：用记事本打开CSV → 另存为 → 编码选择"ANSI" → 再用Excel打开

### Q6：如何修改默认账号密码
**A**：编辑 `server/api/auth.py`，修改 `USERS` 字典中的用户名和密码：
```python
USERS = {
    "admin": {"password": "你的新密码", "role": "admin", "name": "管理员"},
}
```

### Q7：Python 3.13 可以用吗
**A**：不推荐。部分依赖库（如 uiautomator2、playwright）可能不兼容 Python 3.13。
- 推荐使用 Python 3.10 或 3.11
- 如已安装 3.13，建议卸载后安装 3.10.11

### Q8：如何让局域网其他设备访问前端
**A**：编辑 `vite.config.js`，添加 `host: '0.0.0.0'`：
```js
server: {
  host: '0.0.0.0',
  port: 5173
}
```
然后其他设备通过 `http://你的IP:5173` 访问。

### Q9：数据存在哪里
**A**：所有数据存储在 `server/data/` 目录下的 JSON 文件中：
- `articles.json` — 文章数据
- `accounts.json` — 账号数据
- `titles.json` — 标题数据
- `topics.json` — 话题数据
- `commands.json` — 指令数据
- `settings.json` — 设置数据

> ⚠️ 生产环境建议改用 SQLite 或 MySQL 数据库，JSON 文件仅适合开发测试。

### Q10：如何重置所有数据
**A**：删除 `server/data/` 目录下的所有 JSON 文件，重启后端即可自动重建空数据。
