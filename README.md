## 🚀 快速开始

### 环境要求

| 软件 | 最低版本 | 推荐版本 |
|------|---------|---------|
| Node.js | 16.0 | 18.x / 20.x |
| npm | 8.0 | 9.x / 10.x |
| Python | 3.9 | 3.10 / 3.11 |
| pip | 21.0 | 最新版 |

> ⚠️ **重要**：Python 不建议使用 3.13 等过新版本，部分依赖库（如 uiautomator2、playwright）可能不兼容。推荐使用 Python 3.10 或 3.11。

### 安装步骤

#### 1. 克隆或下载项目

将项目放置到任意目录，例如：
```
D:\Tools\罐头\xiangcaipy
```

#### 2. 安装前端依赖

```bash
cd xiangcaipy
npm install
```

#### 3. 安装后端依赖

```bash
cd server
pip install -r requirements.txt
```

#### 4. 安装Playwright浏览器（首次使用）

```bash
playwright install chromium
```

## ⚙️ 启动方式

### 方式一：双击启动脚本（推荐 Windows 用户）

项目根目录提供了两个启动脚本：

| 脚本 | 作用 | 端口 |
|------|------|------|
| `start_frontend.bat` | 启动前端开发服务器 | 5173 |
| `start_server.bat` | 启动后端 FastAPI 服务 | 9527 |

**使用方法**：
1. 双击 `start_server.bat` 启动后端（等待显示 "Application startup complete"）
2. 双击 `start_frontend.bat` 启动前端（等待显示 "Local: http://localhost:5173"）
3. 打开浏览器访问 `http://localhost:5173`

### 方式二：命令行启动

#### 启动后端

```bash
cd xiangcaipy\server
python main.py
```

后端启动成功后会显示：
```
INFO:     Uvicorn running on http://0.0.0.0:9527
INFO:     Application startup complete.
```

#### 启动前端

新开一个命令行窗口：

```bash
cd xiangcaipy
npm run dev
```

前端启动成功后会显示：
```
  VITE v5.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
```

### 方式三：生产构建部署

```bash
# 构建前端
cd xiangcaipy
npm run build

# 构建产物在 dist/ 目录，可部署到 Nginx 等静态服务器
# 后端使用 uvicorn 生产启动：
cd server
uvicorn main:app --host 0.0.0.0 --port 9527 --workers 2
```

## 📖 功能使用指南

### 1. 标题采集

**访问路径**：`/title-spider`

#### 1.1 启动采集
1. 确保MuMu模拟器已启动，百度App已登录（小号！）
2. 点击绿色"启动采集"按钮
3. 爬虫自动滑动采集百度信息流标题
4. 采集完成后自动停止，显示采集数量

#### 1.2 筛选标题
- **阅读量筛选**：输入最低阅读量，筛选高阅读量标题
- **关键词搜索**：按标题关键词搜索
- **状态筛选**：按使用状态筛选（未使用/已使用）

#### 1.3 AI重写爆款标题
1. 勾选需要重写的标题（支持全选）
2. 点击"豆包AI重写标题"按钮
3. 在弹窗中确认重写指令（可自定义）
4. 点击"开始重写"，系统自动打开豆包AI网页版
5. 等待AI生成完成（每个标题生成5条仿写标题）
6. 在结果中勾选想要的仿写标题（AI生成标题带《》标识）
7. 选择文章类型和付费类型
8. 点击"加入文章生成列表"

#### 1.4 直接加入生成列表
1. 勾选标题
2. 点击"加入生成列表"按钮
3. 选择文章类型和付费类型
4. 点击确定，自动添加到文章生成队列

---

### 2. 文章生成

**访问路径**：`/article-generate`

#### 2.1 生成队列管理
- 显示所有待生成的文章
- 支持分页（10/15/20条/页）
- 支持全选和批量操作
- 可手动编辑标题
- 可单篇修改文章类型

#### 2.2 批量修改文章类型
1. 勾选需要修改的文章（支持全选）
2. 顶部出现批量操作栏
3. 选择目标文章类型
4. 点击"应用类型"按钮
5. 更新成功后自动刷新表格

#### 2.3 批量启动生成
1. 勾选需要生成的文章（不勾选则生成全部）
2. 选择AI平台（默认智谱AI）
3. 选择AI账号（必须选择，否则按钮禁用）
4. 选择是否生成配图（默认开启，使用豆包生成）
5. 点击"启动批量生成"按钮
6. 系统按顺序逐个生成文章+配图
7. 实时显示生成进度和状态
8. 单篇生成失败自动跳过，继续下一篇
9. 单篇最大超时时间6分钟

#### 2.4 生成配置说明
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| AI平台 | 生成文章使用的AI | 智谱AI |
| AI账号 | 选择具体的AI账号 | 必须手动选择 |
| 生成配图 | 是否同时生成文章配图 | 开启（使用豆包） |

## 🔌 API 文档

后端启动后，访问以下地址查看完整的 API 文档：

- **Swagger UI**：http://127.0.0.1:9527/docs
- **ReDoc**：http://127.0.0.1:9527/redoc

### API 模块清单

| 模块 | 前缀 | 说明 |
|------|------|------|
| 认证 | `/api/auth` | 登录、登出、当前用户 |
| 文章管理 | `/api/article` | 列表、详情、创建、更新、删除、批量操作、导出 |
| 文章生成 | `/api/ai-generate` | 生成队列、批量生成、任务状态 |
| 标题采集 | `/api/spider` | 列表、启动、停止、状态、重写、标记、导出、删除 |
| AI配置 | `/api/ai-config` | 文章类型、提示词、AI账号 |
| 账号管理 | `/api/account` | 5平台账号CRUD+登录+启用 |
| 话题管理 | `/api/topic` | 列表、创建、更新、删除、启用 |
| 指令队列 | `/api/command` | 列表、统计、重试、清空、删除、WebSocket |
| 系统设置 | `/api/settings` | 全部设置、分类设置、保存 |
| 日志监控 | `/api/logs` | 列表、级别统计、搜索 |
| 全局 | `/api/global` | 健康检查、全局状态 |

### 前端代理配置

前端开发服务器通过 Vite 代理将 `/api` 请求转发到后端：

```js
// vite.config.js
server: {
  proxy: {
    '/api': {
      target: 'http://127.0.0.1:9527',
      changeOrigin: true
    }
  }
}
```

> 如果后端端口不是9527，请修改 `vite.config.js` 中的 `target` 地址。

## ⚙️ 配置说明

### 前端配置

#### 修改前端端口
编辑 `vite.config.js`：
```js
server: {
  port: 5173,  // 修改为其他端口
  host: '0.0.0.0'  // 允许局域网访问
}
```

#### 修改后端代理地址
编辑 `vite.config.js`：
```js
proxy: {
  '/api': {
    target: 'http://127.0.0.1:9527',  // 修改为后端实际地址
    changeOrigin: true
  }
}
```

### 后端配置

#### 修改后端端口
编辑 `server/main.py` 末尾：
```python
uvicorn.run(
    "main:app",
    host="0.0.0.0",
    port=9527,  // 修改为其他端口
    reload=False
)
```

> ⚠️ 修改后端端口后，必须同步修改 `vite.config.js` 中的代理地址和 `start_server.bat` 中的端口显示。

## ❓ 常见问题

### Q1：启动前端报错 "Cannot find module"
**A**：依赖未安装，执行：
```bash
npm install
```

### Q2：启动后端报错 "ModuleNotFoundError: No module named 'fastapi'"
**A**：后端依赖未安装，执行：
```bash
cd server
pip install -r requirements.txt
```

### Q3：前端页面显示空白或接口报错
**A**：检查后端是否已启动。前端通过 `/api` 代理访问后端，后端必须先启动。
- 后端地址：http://127.0.0.1:9527
- 健康检查：http://127.0.0.1:9527/api/health

### Q4：登录后又跳回登录页
**A**：Token过期或被清除。检查浏览器 localStorage 中是否有 `xiangcai_token`。
- 解决方法：重新登录

### Q5：文章生成按钮是灰色的，无法点击
**A**：必须选择AI账号后才能启动生成。
- 解决方法：在"选择账号"下拉框中选择一个AI账号

### Q6：批量生成时，某篇文章生成失败会怎么样？
**A**：系统会自动跳过失败的文章，继续生成下一篇，不会中断整体任务。
- 失败的文章会显示错误信息，可以重新勾选后再次生成

### Q7：AI重写标题时，浏览器自动关闭了怎么办？
**A**：可能是生成超时或网络问题。
- 解决方法：减少一次重写的标题数量（建议不超过5个），确保网络稳定

### Q8：如何修改默认账号密码
**A**：编辑 `server/api/auth.py`，修改 `USERS` 字典中的用户名和密码。

### Q9：Python 3.13 可以用吗？
**A**：不推荐。部分依赖库（如 uiautomator2、playwright）可能不兼容 Python 3.13。
- 推荐使用 Python 3.10 或 3.11

### Q10：数据存在哪里？
**A**：所有数据存储在 `server/data/` 目录下的 JSON 文件中：
- `articles.json` — 文章数据
- `titles.json` — 标题数据
- `generate_queue.json` — 生成队列数据
- `ai_config.json` — AI配置数据
- `accounts.json` — 账号数据
- `topics.json` — 话题数据
- `commands.json` — 指令数据
- `settings.json` — 设置数据
- `batch_tasks.json` — 批量任务数据

### Q11：如何重置所有数据？
**A**：删除 `server/data/` 目录下的所有 JSON 文件，重启后端即可自动重建空数据。

### Q12：端口被占用怎么办？
**A**：修改后端端口（建议使用不常用的端口，如9527、8888、9999）。
- 修改 `server/main.py` 中的端口
- 修改 `vite.config.js` 中的代理地址
- 修改 `start_server.bat` 中的端口显示
